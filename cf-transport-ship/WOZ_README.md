# WOZ 生化战场（World of Zombies）

基于本框架（Three.js 网页 FPS）二次开发的**生化战场**完整实现，**五大模式 × 两张地图**（单机 vs BOT，原团队竞技模式保留）。

## 游戏模式

| 模式 | 玩法 |
| --- | --- |
| **生化感染** | 母体感染链：开局随机 2 母体（3000HP），人类被爪杀即转化为变异者；撑满 180s 或全歼变异者=人类胜，全员感染=变异者胜 |
| **生化复仇** | 感染框架 + 变异者复活再变异（HP×1.25/伤×1.2）+ 人类濒败觉醒**生化复仇者**（1500HP 电锯轻击 500/重击必杀/禁复活）+ 最后 60s AI 尸潮 |
| **生化模式** | 感染变体：地图周期刷新 **AI 怪物**（300HP），击杀掉落医疗/弹药/生化能量（技能充满）补给 |
| **生化对抗** | 人类攻方 vs 变异者守方：占领 **A/B/C 三大战术据点**（站内人数优势推进进度，争夺冻结），全占=人类胜，守到时间耗尽=变异者胜；守卫分区驻守 |
| **生化爆破** | 人类攻入变异者巢穴**安放核弹**（4s 吟唱），**率先安放者进化为英雄**（200HP/伤害×1.25/加速）；核弹引爆=人类胜，守卫吟唱 8s 摧毁或团灭人类=变异者胜；守卫限量复活 |

先胜 3 回合赢下对局（对抗/爆破同规则）。

## 变异者

- **利爪**：左键轻击 40 / 右键重击 75，受视线遮挡约束（不可隔墙命中），出手解除出生保护
- **七变异者**（原作名单：噬魂者/猎食者/夜行者/缠绕者/爆破者 + AI 型爬行者/断头者[可附身]；子体变身 **键盘 5/6/7/8/9/0/-** 快捷切换，右下按钮可点；技能 **G/F** 均可释放）。技能机制（调研对齐原作）：**感染后技能立即可用，使用后进入各自独立冷却**，受伤/吞噬可加速回充：
  - **[5] 夜行者**：最速，技能[疾冲 冷却 15s]——向前突进
  - **[6] 噬魂者**：技能[致盲尖啸 冷却 25s]——18m 内人类致盲 3s
  - **[7] 猎食者**：4000 HP 坦克，技能[投掷斧头 冷却 20s]——300 伤旋转斧抛射（重力弧线，可被墙体拦截）
  - **[8] 缠绕者**：1800 HP，技能[缠绕 冷却 6s·原作"可随时使用"]——准星 14° 内 22m 触须抓取：定身 1.2s + 拖拽 9m/s + 60 伤
  - **[9] 爆破者**：2200 HP，技能[自爆 冷却 30s]——点燃引信 1.2s 冲锋（移速 ×1.3），爆炸 7m 半径 700 伤（距离衰减），击杀走感染链，自身阵亡
  - **[0] 爬行者**（V51）：3600 HP 蜥蜴巨躯（体型 1.24/沼泽绿皮），**纯属性型无技能**（原作设定）——躯体减伤 40%、爆头 1.5× 伤并**定身 0.9s**（原作"抗击打强/被爆头停止移动"）
  - **[-] 断头者**（V52）：2800 HP 双大刀处刑型（体型 1.15/冷钢灰皮，纯属性型无技能）——轻击 ×1.75（70 伤）、**重击 ×2.65（199 伤近身秒杀满血人类**，原作"时常可以秒杀对手"），全变异者最迟缓
- **吞噬进化**：E 键吞噬变异者尸体，+300 血、+1 进化点（每点 +2% 伤害 +50 血上限）
- **进化阶段**（原作：防御/攻击/再次变异/特殊进化）：吞噬 3 次=一阶攻击 +15%；6 次=二阶减伤 15%；9 次=三阶特殊进化（HP 上限 +500 / 移速 +8% / 体型红光）
- 母体 3000 HP，感染人类回 500 血，技能[狂暴咆哮 冷却 30s]；BOT 子体感染后随机变身职业并按语境用技
- **生化复仇者**：1500 HP 电锯（轻 500/重击 360° 旋转清场必杀），被动减伤 30%
- 人类侧：进化档位（速度/弹药/**威力 Lv3 +10%**/减伤，上限 4 档）；满档解锁**必杀技[V] 狂暴**（5s 伤害 ×1.5 + 瞬间满弹，冷却 60s）
- **补给空投**：感染族战斗期每 60s 空投全补给箱（降落伞降落/雷达金菱形📦/走近拾取=弹药补满+医疗+手雷）；**每第 3 个为金色武器空投**（★ 星标/更大雷达标记，内含 AWM/M60/加特林/波波沙/温彻斯特/龙息霰弹/M79 随机稀有枪，拾取替换主武器满弹药）

### 机制细节
- **感染原地转化**：人类被爪杀后在**原地**变异起身（对齐原作，不去复活点）
- **变异者蛰伏回血**：变异者静止不动时持续缓慢回血（上限为当前形态血池）
- **电锯持续伤害**：按住左键持续切割（约 500 DPS 无间隔），右键重击必杀（1.2s 冷却）
- **复仇者保留武器**：变身复仇者只把军刀槽换成电锯，主武器/副武器/投掷武器仍可随时切换
- **按当前武器决定移速**：持加特林移速慢、持手枪/刀快，切枪即时生效
- **武器丢弃/拾取**：G 丢出当前主/副武器（带剩余弹药掉落），E 拾取地上的武器（同槽自动交换）

## 开发

```bash
npm install --registry=https://registry.npmmirror.com   # package-lock 锁内网源，首次需删除重装
node build.mjs                        # 构建单文件 dist/index.html

node src/woz/rules.test.mjs           # 规则层 41 项断言（零依赖，node 直跑）
node scripts/smoke.mjs                # TDM 回归冒烟（Edge 无头）
node scripts/woz-e2e.mjs              # 感染+复仇 端到端 15 项验收
node scripts/woz-e2e2.mjs             # 对抗+爆破+生化 端到端 16 项验收
node scripts/woz-balance.mjs <mode> <n> [map]  # 平衡探针（可指定地图）
```

## 实现结构

```
src/woz/
  config.js      # 全部数值（CONFRONT/DEMOL/BIO 三模式参数）
  rules.js       # 感染/复仇规则状态机（纯逻辑，node 直测）
  objectives.js  # 据点占领 + 核弹装置状态机
  zombie.js      # 变异者 AI（近战追击 + NavGrid + 人类 BOT 感染改造）
  integrate.js   # WozManager：五模式集成（开局/每帧/死亡重生/BOT战术/伤害/结算）
  pickups.js     # 生化模式补给掉落
  map-city.js    # 死亡城市地图（三线街区/夜景/跳点守位）
  hud.js         # WOZ HUD（身份牌/技能充能/据点归属/核弹倒计时/致盲遮罩/变身）
  audio.js       # 合成音效（嘶吼/转化/疾冲/尖啸/硬化/吞噬/觉醒/尸潮号角）
scripts/          # smoke / woz-e2e / woz-e2e2 / woz-balance 四套自动化
```
